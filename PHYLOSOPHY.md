# BDQueue Philosophy

BDQueue is intentionally small.

It exists to help people remember birthdays without turning
a human moment into a product.

## What this project is

- A shared birthday timeline
- A gentle reminder system
- A reference implementation

## What this project is not

- A social network
- A growth tool
- A notification engine
- A SaaS

## Design principles

- No accounts
- No feeds
- No engagement tricks
- No dark patterns
- Minimal data collection

If a feature increases complexity without increasing meaning,
it does not belong here.

Fork freely.
Change boldly.
Keep it human.
