# BDQueue

A minimal birthday timeline for small groups.

## What it does

BDQueue lets people drop their birthdays into a shared timeline.
No logins. No noise. Just remembering.

Built for WhatsApp groups, families, teams, and friends.

## Demo

Live demo: <https://bdqueue.nijue.me>

## Tech Stack

- Next.js (App Router)
- Firebase (Firestore)
- Resend (emails)
- Tailwind CSS
- shadcn/ui

## Running Locally

### Getting started

1. Clone the repo
2. Copy `.env.example` to `.env`
3. Add Firebase and Resend keys
4. Run `npm install && npm run dev`
